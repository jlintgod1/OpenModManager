### What is this? A fork in a flying boat?

It's m_cube/mcu8's Open Mod Manager (OMM) but with additional features like:
 - Better AlwaysLoaded functionality!
 - Auto Workshop Blocker
 - (Slightly untested) Automatic Screenshot Uploader (so Steam doesn't complain about your .bmp and large .jpg files) 
 - Slightly better formatting and bug fixes
 - Jlintgod (the Spider) and his "humor"
 - Sketchy code!

Precompiled Binaries are now available on the [Releases](https://github.com/jlintgod1/OpenModManager/releases/latest) tab!

⚠️ Works only with the **Steam version** of *A Hat in Time* and **64-bit operating systems** (since the game is 64-bit anyway).  
🛠 Requires [.NET Framework v4.8](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48).


Installation
---
> [!WARNING]
> The "latest release" is relatively out of date, with it lacking the Automatic Screenshot Uploader and User Experience tag, along with it having a bug that prevents a mod icon from being selected. New binaries will come out TBD.

> [!NOTE]
> If Windows Smartscreen blocks the executable from running, click "Run Anyway." (If you don't see it, click "More Info.")

1. Download the latest release from the [Releases](https://github.com/mcu8/OpenModManager/releases/latest) page.  
2. Extract it to any folder.  
3. Run the `ModdingTools.exe` executable.

Building from Source
---
1. Clone the repository.  
2. Open the solution in **Visual Studio 2022** or newer.
